void PreOrderNonRecursive(BiTree T) {
    Stack S;
    InitStack(S);            // 初始化栈
    BiTree p = T;            // p为遍历指针
    
    // 循环条件：p不为空 或 栈不为空
    while (p != NULL || !StackEmpty(S)) {
        if (p != NULL) {
            printf("%d ", p->data); // 1. 访问根节点
            Push(S, p);             // 2. 根节点入栈（为了以后能找回右孩子）

        } else {
            Pop(S, p);              // 4. 栈顶弹出（回溯）
            p = p->rchild;          // 5. 向右走
        }
    }
}

## 3. 求二叉树深度（高度）
**考点**：递归思想，树深 = max(左深, 右深) + 1。

```c
int GetDepth(BiTree T) 
{
    if(T == NULL) 
    {
        return 0;            // 空树深度为0
    }else 
    {
        int m = GetDepth(T->lchild); // 求左子树深度
        int n = GetDepth(T->rchild); // 求右子树深度
        
        // 返回较大的那个 + 1（根节点）
        return (m > n ? m : n) + 1;
    }
}

# 第六章

在二叉树的学习中，计算题是核心考点。我将这些知识点总结为**四大类核心公式**，掌握了这些，基本可以解决 90% 的二叉树定量分析问题。

---

### 一、 结点数与度数的通用性质（最常考）

设 $n$ 为总结点数，$n_0$ 为叶子结点数，$n_1$ 为度为 1 的结点数，$n_2$ 为度为 2 的结点数。

1.  **结点总数公式**：
    $$n = n_0 + n_1 + n_2$$
2.  **分支总数（边数）关系**：
    *   从下往上看：每个结点（除根节点外）上面都连着一根线，所以 **分支数 = $n - 1$**。
    *   从上往下看：度为 1 的结点产生 1 个分支，度为 2 的结点产生 2 个分支，所以 **分支数 = $n_1 + 2n_2$**。
3.  **核心推导结论（必背）**：
    由 $n-1 = n_1 + 2n_2$ 和 $n = n_0 + n_1 + n_2$ 联立得：
    $$n_0 = n_2 + 1$$
    *即：叶子结点的数量总是比度为 2 的结点数量多一个。*

---

### 二、 树的高度与结点数的关系

设 $h$ 为二叉树的高度（深度）。

1.  **第 $i$ 层最多结点数**：$2^{i-1}$
2.  **高度为 $h$ 的二叉树最多结点数（满二叉树）**：$2^h - 1$
3.  **高度为 $h$ 的二叉树最少结点数**：$h$（退化为单支树）
4.  **具有 $n$ 个结点的二叉树的最小高度**：
    $$h = \lceil \log_2(n+1) \rceil \quad \text{或} \quad h = \lfloor \log_2 n \rfloor + 1$$

---

### 三、 完全二叉树（CBT）的特有性质

完全二叉树是指除了最后一层外，其他层都是满的，且最后一层结点连续集中在左侧。

1.  **已知 $n$，求 $n_0, n_1, n_2$**：
    *   在完全二叉树中，$n_1$ 只能等于 **0 或 1**。
    *   如果 $n$ 是**奇数**，则 $n_1 = 0$。
    *   如果 $n$ 是**偶数**，则 $n_1 = 1$。
2.  **叶子结点数 $n_0$ 的快捷计算**：
    $$n_0 = \lceil n/2 \rceil$$
3.  **最后一个非叶子结点的编号**：$\lfloor n/2 \rfloor$（常用于堆排序的建堆起始点）。
4.  **结点 $i$ 的父子关系（下标从 1 开始）**：
    *   左孩子编号：$2i$（若 $2i > n$ 则无左孩子）。
    *   右孩子编号：$2i + 1$（若 $2i+1 > n$ 则无右孩子）。
    *   双亲（父节点）编号：$\lfloor i/2 \rfloor$。

---

### 四、 哈夫曼树与带权路径长度（WPL）

1.  **哈夫曼树的结点总数**：
    若有 $n$ 个叶子结点（权值），则哈夫曼树的总结点数为：
    $$N = 2n - 1$$
    *原因：哈夫曼树没有度为 1 的结点（$n_1 = 0$），结合 $n_0 = n_2 + 1$，得 $n_2 = n - 1$，总数 $n + (n-1) = 2n-1$。*
2.  **WPL 计算**：
    $$WPL = \sum_{i=1}^{n} w_i l_i$$
    *其中 $w_i$ 是权值，$l_i$ 是该路径长度（层数 - 1）。*
    **技巧**：WPL 也等于所有**非叶子结点**的权值之和（构造过程中两两相加产生的中间值总和）。

---

### 五、 补充：二叉树的形态计算

1.  **卡特兰数 (Catalan Number)**：
    已知 $n$ 个**不同**的结点，能组成多少种**不同形态**的二叉树？
    $$C = \frac{1}{n+1} C_{2n}^n$$
    例如：3个结点可以组成 5 种形态。

---

### 综合练习题

**题目**：一棵完全二叉树有 1000 个结点，求其叶子结点数、度为 1 的结点数、以及高度。

**解析**：
1.  **求高度**：
    $2^9 - 1 = 511$, $2^{10} - 1 = 1023$。
    因为 $511 < 1000 < 1023$，所以高度 **$h = 10$**。
2.  **求 $n_1$**：
    总数 $n = 1000$ 是偶数，根据完全二叉树性质，**$n_1 = 1$**。
3.  **求 $n_0$**：
    方法一：公式法 $n_0 = \lceil 1000/2 \rceil = 500$。
    方法二：列方程
    $n_0 + n_1 + n_2 = 1000$
    $n_0 + 1 + (n_0 - 1) = 1000$（利用 $n_2 = n_0 - 1$）
    $2n_0 = 1000 \Rightarrow \mathbf{n_0 = 500}$。
4.  **求 $n_2$**：
    $n_2 = n_0 - 1 = 499$。

**检查**：$500 + 1 + 499 = 1000$。正确。

# 第七章 查找 (Search) 核心代码

> **复习提示**：
> 1. **下标约定**：严蔚敏《数据结构》中，顺序表的查找通常**从下标 1 开始存放数据**（下标 0 常用于做“哨兵”或闲置）。因此，`low` 初始为 1，`high` 初始为 `length`。
> 2. **返回值**：通常返回下标。如果找不到，返回 `0`。

## 0. 查找表的数据结构定义

    int length;    // 表长度
} SSTable;
```

## 1. 折半查找：递归实现 (修正版)
**考点**：必须写出递归结束条件 `low > high`，否则扣大分。

```c
int BinarySearch_Rec(SSTable *ST, int key, int low, int high) {
    // 1. 【核心】递归出口：查找范围无效，说明没找到
    if (low > high) {
        return 0;  // 查找失败，返回0
    }

    // 2. 计算中间位置
    int mid = (low + high) / 2;

    // 3. 比较逻辑
    if (key == ST->elem[mid]) {
        return mid;  // 找到了，返回下标
    }
    else if (key < ST->elem[mid]) {
        // 目标比中间小，在左半区找 (high 变)
        return BinarySearch_Rec(ST, key, low, mid - 1);
    }
    else {
        // 目标比中间大，在右半区找 (low 变)
        return BinarySearch_Rec(ST, key, mid + 1, high);
    }
}
```
*调用方式示例：* `int index = BinarySearch_Rec(&table, 52, 1, table.length);`

## 2. 折半查找：非递归实现 (迭代法·推荐)
**考点**：使用 `while` 循环，空间复杂度更优，**考试首选写法**。

```c
int BinarySearch(SSTable *ST, int key) {
    int low = 1;              // 假设数据从下标1开始
    int high = ST->length;    // 尾部下标
    int mid;

    // 循环条件：只要 low 不超过 high，就继续找
    while (low <= high) {
        mid = (low + high) / 2;

        if (ST->elem[mid] == key) {
            return mid;       // 查找成功
        }
        else if (key < ST->elem[mid]) {
            high = mid - 1;   // 往左缩：修改 high
        }
        else {
            low = mid + 1;    // 往右缩：修改 low
        }
    }

    return 0; // 循环结束还没找到，说明不存在
}
```

## 3. 顺序查找 (带哨兵·补充)
**考点**：利用 `elem[0]` 存目标值，省去每次循环都要判断 `i>=0` 的时间，虽然简单但可能会考填空或改错。

```c
int Search_Seq(SSTable *ST, int key) {
    // 1. 把 key 存入下标 0 作为“哨兵”
    ST->elem[0] = key; 
    
    int i = ST->length; // 从后往前找
    
    // 2. 只要不相等就一直往前走
    // 如果找不到，最终 i 会停在 0，刚好不用额外判断越界
    while (ST->elem[i] != key) {
        i--;
    }
    
    return i; // 如果返回0说明失败，返回>0说明成功
}
```

## 4. 散列表（Hash）相关公式 (备考填空/应用题)

虽不用背长代码，但以下公式必须记住（对应卷子第9题）：

1.  **构造哈希函数（除留余数法）**：
    $$H(key) = key \% p$$
    *   *注意：p 通常取不大于表长的最大质数。*

2.  **处理冲突（线性探测法）**：
    $$H_i = (H(key) + i) \% m$$
    *   *解释：算出的位置被占了？那就 +1 看下一个，还被占？再 +1。*

3.  **ASL (平均查找长度) 计算思路**：
    *   **ASL_成功** = (每次查找成功的探测次数之和) / 关键码个数
    *   **ASL_失败** = (查找失败也就是对应位置为空所需的探测次数之和) / 模 p 的个数

> **复习约定**：

## 一、 插入排序 (Insertion Sort)

### 1. 直接插入排序 (Direct Insertion Sort)
**适用场景**：$n$ 较小，或数据基本有序。
**算法思想**：把无序区的第一个元素，插入到有序区的合适位置。

```c
void InsertSort(int num[], int n) {
    int i, j;
    // 从第2个元素开始，默认第1个是有序的
    for (i = 2; i <= n; i++) {
        if (num[i] < num[i - 1]) { // 需将 num[i] 插入有序子表
            num[0] = num[i];       // 1. 设置哨兵 (复制为副本)
            
            // 2. 从后往前查找位置，同时后移
            // 这里的 num[0] 既是数据副本，又是哨兵(防止越界)
            for (j = i - 1; num[0] < num[j]; --j) {
                num[j + 1] = num[j]; // 记录后移
            }
            
            // 3. 插入到正确位置
            num[j + 1] = num[0];
        }
    }
}
```
*   **时间复杂度**：平均 $O(n^2)$，最好 $O(n)$。
*   **空间复杂度**：$O(1)$。
*   **稳定性**：稳定。

---

### 2. 折半插入排序 (Binary Insertion Sort)
**适用场景**：$n$ 较大，数据有序。
**算法思想**：查找插入位置时，使用二分查找，减少比较次数（但移动次数不变）。

```c
void BInsertSort(int num[], int n) {
    int i, j, low, high, mid;
    for (i = 2; i <= n; i++) {
        num[0] = num[i];    // 暂存到 num[0]
        
        // --- 核心：折半查找插入位置 ---
        low = 1; 
        high = i - 1;
        while (low <= high) {
            mid = (low + high) / 2;
            if (num[0] < num[mid]) 
                high = mid - 1; // 插入点在左半区
            else 
                low = mid + 1;  // 插入点在右半区
        }
        // 查找结束，插入位置为 high + 1
        
        // --- 移动元素 ---
        for (j = i - 1; j >= high + 1; --j) {
            num[j + 1] = num[j];
        }
        
        num[high + 1] = num[0]; // 插入
    }
}
```
*   **时间复杂度**：$O(n^2)$。
*   **空间复杂度**：$O(1)$。
*   **稳定性**：稳定。

### 3. 希尔排序 (Shell Sort)
**适用场景**：$n$ 较大。
**算法思想**：缩小增量排序。先将序列分成若干子序列分别进行直接插入排序，待基本有序后，再对全体进行一次直接插入排序。

```c
void ShellSort(int num[], int n) {
    int i, j, gap;
    // gap 为增量，初始为长度一半，每次折半，直到 gap=1
    for (gap = n / 2; gap >= 1; gap = gap / 2) {
        
        // 对每一组进行直接插入排序
        for (i = gap + 1; i <= n; ++i) {
            if (num[i] < num[i - gap]) {
                num[0] = num[i]; // 暂存
                
                // 查找插入位置，跨度为 gap
                for (j = i - gap; j > 0 && num[0] < num[j]; j -= gap) {
                    num[j + gap] = num[j]; // 后移
                }
                
                num[j + gap] = num[0]; // 插入
            }
        }
    }
}
```
*   **时间复杂度**：平均约 $O(n^{1.3})$，最坏 $O(n^2)$。
*   **空间复杂度**：$O(1)$。
*   **稳定性**：**不稳定**（跳跃交换导致）。

### 4. 【试卷考点】双向链表上的直接插入排序
**注意**：这是你试卷大题的考点。双向链表不需要移动元素，只需要断开指针重新链接。

```c
typedef struct DNode {
    int data;
    struct DNode *prior, *next;
} DNode, *DLinkList;

void DInsertSort(DLinkList L) {
    DNode *p, *q, *pre;
    // p 指向当前待排序节点，从第2个节点开始 (L->next 是第1个)
    if(L->next == NULL) return; // 空表或只有1个元素
    
    p = L->next->next; 
    
    while (p != NULL) {
        // q 记录 p 的下一个，防止断链后找不到路
        q = p->next; 
        
        // pre 指向 p 的前驱
        pre = p->prior;
        
        // 如果当前节点 p 小于它的前驱，需要调整
        if (p->data < pre->data) {
            
            // 1. 把 p 摘下来（断开 p）
            pre->next = p->next;
            if (p->next != NULL) { // 注意检查尾节点
                p->next->prior = pre; 
            }
            
            // 2. 向前找插入位置
            // 只要 pre 不指向头结点 且 pre 的数据比 p 大，就一直往前找
            while (pre != L && pre->data > p->data) {
                pre = pre->prior;
            }
            
            // 此时 pre 指向要插入位置的前一个节点
            // 3. 将 p 插入到 pre 之后
            p->next = pre->next;
            pre->next->prior = p;
            p->prior = pre;
            pre->next = p;
        }
        
        // 继续处理下一个
        p = q;
    }
}
```

## 二、 交换排序 (Exchange Sort)

### 1. 冒泡排序 (Bubble Sort)
```c
void BubbleSort(int num[], int n) {
    int i, j, exchange;
    int temp;
    for (i = 1; i < n; i++) { // 最多做 n-1 趟
        exchange = 0; // 标记本趟是否发生交换
        
        for (j = 1; j <= n - i; j++) { // 从头扫到尾
            if (num[j] > num[j + 1]) {
                temp = num[j];
                num[j] = num[j + 1];
                num[j + 1] = temp;
                exchange = 1;
            }
        }
        // 如果本趟没有发生交换，说明已经有序，提前结束
        if (exchange == 0) return;
    }
}
```
*   **时间**：$O(n^2)$。 **空间**：$O(1)$。 **稳定性**：稳定。

### 2. 快速排序 (Quick Sort) —— **必考代码**
**核心**：Partition (一次划分) + 递归。

```c
// --- 核心：划分函数 ---
int Partition(int num[], int low, int high) {
    // 用子表的第一个记录作枢轴记录
    num[0] = num[low]; 
    int pivotkey = num[low];
    
    while (low < high) { 
        // 1. 从右向左找比枢轴小的
        while (low < high && num[high] >= pivotkey) 
            high--;
        num[low] = num[high]; // 移到左端
        
        // 2. 从左向右找比枢轴大的
        while (low < high && num[low] <= pivotkey) 
            low++;
        num[high] = num[low]; // 移到右端
    }
    
    num[low] = num[0]; // 枢轴归位
    return low;        // 返回枢轴位置
}

// --- 递归排序函数 ---
void QSort(int num[], int low, int high) {
    if (low < high) {
        // 算出枢轴位置
        int pivotloc = Partition(num, low, high);
        
        // 递归排左边
        QSort(num, low, pivotloc - 1);
        // 递归排右边
        QSort(num, pivotloc + 1, high);
    }
}

// --- 统一接口 ---
void QuickSort(int num[], int n) {
    QSort(num, 1, n);
}
```
*   **时间**：平均 $O(n \log n)$ (最快)，最坏 $O(n^2)$。
*   **空间**：$O(\log n)$ (递归栈深度)。
*   **稳定性**：**不稳定**。

## 三、 选择排序 (Selection Sort)

### 1. 简单选择排序 (Simple Selection Sort)
```c
void SelectSort(int num[], int n) {
    int i, j, k, temp;
    for (i = 1; i < n; i++) { // 做 n-1 趟
        k = i; // k 记录当前最小值的下标
        
        for (j = i + 1; j <= n; j++) { // 在后面找更小的
            if (num[j] < num[k]) 
                k = j;
        }
        
        // 如果最小值不是 i 自己，交换
        if (k != i) {
            temp = num[i];
            num[i] = num[k];
            num[k] = temp;
        }
    }
}
```
*   **时间**：$O(n^2)$。 **空间**：$O(1)$。 **稳定性**：**不稳定**。

### 2. 堆排序 (Heap Sort) —— **难点**
**核心**：建立大顶堆 + 堆调整。

```c
// --- 堆调整 (筛选) ---
// 假设 num[s+1...m] 已经是堆，将 num[s] 调整进去
void HeapAdjust(int num[], int s, int m) {
    int rc = num[s]; // 暂存堆顶
    int j;
    
    // j 沿 key 较大的孩子节点向下筛选
    for (j = 2 * s; j <= m; j *= 2) 
    {
        // 选出左右孩子中较大的那个 (j 指向大的)
        if (j < m && num[j] < num[j + 1]) 
            j++;
            
        // 如果堆顶比最大的孩子还大，说明不用调了
        if (rc >= num[j]) 
            break;
        
        num[s] = num[j]; // 把大的孩子上移
        s = j;           // s 跟随向下
    }
    num[s] = rc; // 放入最终位置
}

// --- 堆排序主函数 ---
void HeapSort(int num[], int n) 
{
    int i, temp;
    
    // 1. 建堆 (从最后一个非叶子节点 n/2 开始)
    for (i = n / 2; i > 0; i--) 
    {
        HeapAdjust(num, i, n);
    }
    
    // 2. 排序 (输出堆顶，交换到数组尾部)
    for (i = n; i > 1; i--) 
    {
        // 交换堆顶 num[1] 和当前队尾 num[i]
        temp = num[1];
        num[1] = num[i];
        num[i] = temp;
        
        // 重新调整剩下的 i-1 个元素为堆
        HeapAdjust(num, 1, i - 1);
    }
}
```
*   **时间**：$O(n \log n)$。
*   **空间**：$O(1)$。
*   **稳定性**：**不稳定**。

## 四、 归并排序 (Merge Sort)

### 2-归并排序
**算法思想**：**分治法** (Divide and Conquer)。
1.  **分**：把数组拦腰切断，分成两个子序列，递归地切，直到长度为1。
2.  **治（合）**：把两个有序的子序列合并成一个有序的序列。

**代码要点**：
*   需要一个**辅助数组** `temp[]` 来暂存合并后的数据。
*   `Merge` 函数负责合并，`MSort` 函数负责递归拆分。

```c
// --- 核心：合并函数 ---
// 将有序的 SR[i..m] 和 SR[m+1..n] 归并为有序的 TR[i..n]
// 这里的实现为了方便背诵，通常使用一个全局或外部传入的辅助数组 temp
void Merge(int num[], int temp[], int low, int mid, int high) 
{
    int i = low;      // 左半区起点
    int j = mid + 1;  // 右半区起点
    int k = low;      // 辅助数组 temp 的游标
    
    // 1. 只要左右两边都有剩余，就比大小，把小的搬到 temp 里
    while (i <= mid && j <= high) {
        if (num[i] <= num[j]) { // <= 保证稳定性
            temp[k++] = num[i++];
        } else {
            temp[k++] = num[j++];
        }
    }
    
    // 2. 如果左边还有剩，全部拷过去
    while (i <= mid) {
        temp[k++] = num[i++];
    }
    
    // 3. 如果右边还有剩，全部拷过去
    while (j <= high) {
        temp[k++] = num[j++];
    }
    
    // 4. 【关键】把排好序的 temp 里的数据拷回原数组 num
    for (i = low; i <= high; i++) {
        num[i] = temp[i];
    }
}

// --- 递归主程序 ---
void MSort(int num[], int temp[], int low, int high) {
    if (low < high) { // 只要区间长度大于1
        int mid = (low + high) / 2;
        
        MSort(num, temp, low, mid);      // 递归排左半边
        MSort(num, temp, mid + 1, high); // 递归排右半边
        
        Merge(num, temp, low, mid, high); // 合并两边
    }
}

// --- 统一接口 ---
// 考试时如果允许动态分配，可以在这里 malloc temp
void MergeSort(int num[], int n) {
    // 申请辅助空间，大小与原数组一致
    int *temp = (int *)malloc((n + 1) * sizeof(int)); 
    if (temp) {
        MSort(num, temp, 1, n); // 假设从下标1开始
        free(temp); // 用完记得释放
    }
}
```

### 算法分析
*   **时间复杂度**：每一趟归并是 $O(n)$，总共层高 $\log n$，所以是 **$O(n \log n)$**。无论最好、最坏情况都是这个速度。
*   **空间复杂度**：**$O(n)$**。这是它最大的缺点，需要和原数组一样大的辅助空间。
*   **稳定性**：**稳定**。

## 五、 最终完整对比表 (含归并)

**必背口诀：**
> 快、希、选、堆 **不稳定**；（其他的都稳定）
> 快、归、堆 **$O(n \log n)$**；（其他的都慢）

| 排序算法 | 平均时间 | 最坏时间 | 空间复杂度 | 稳定性 | 核心特点评价 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **直接插入** | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **稳定** | $n$ 小且基本有序时最快 |
| **折半插入** | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **稳定** | 比直接插入比较次数少 |
| **希尔排序** | $O(n^{1.3})$| $O(n^2)$ | $O(1)$ | 不稳定 | 突破 $O(n^2)$ 的先锋 |
| **冒泡排序** | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **稳定** | 代码最简单，效率低 |
| **快速排序** | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | 不稳定 | **综合性能最好**，最常用 |
| **简单选择** | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 不稳定 | 移动次数最少 |
| **堆排序** | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | 不稳定 | 适合大数据量，**省空间** |
| **归并排序** | $O(n \log n)$ | $O(n \log n)$ | **$O(n)$** | **稳定** | 效率高且稳定，但**费内存** |

**一句话总结选择策略：**
1.  **若 $n$ 较小**：首选 **直接插入排序**（稳定、简单）。
2.  **若 $n$ 很大**：
    *   追求速度：**快速排序**（平均性能最好）。
    *   内存紧张：**堆排序**（空间 $O(1)$）。
    *   要求稳定：**归并排序**（但费内存）。
3.  **若基本有序**：**直接插入排序** 或 **冒泡排序**。
